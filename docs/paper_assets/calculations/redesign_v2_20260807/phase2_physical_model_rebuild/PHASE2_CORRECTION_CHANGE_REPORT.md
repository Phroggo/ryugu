## 4. Results

### Battery determination
**4× Li-ion 18650 (Table I) confirmed as the intended design.** Reasoning,
not just chronology: it names a real, standardized, sourceable form factor
with a specific datasheet-backed part already behind it (Panasonic
NCR18650B, Phase 1); "Ni-MH" in the code was a generic chemistry label
with no specific part, size, or capacity ever attached anywhere in the
project; Li-ion is the realistic modern choice for a mass-constrained
platform (Ni-MH's energy density is roughly 2–4× worse per kg, a real
cost on a 2.3kg total-mass design). The code was corrected to match the
paper/audit, not the other way around, per the user's own stated
fallback. **Zero mass/inertia impact** — confirmed the existing Phase 1/2
numbers were already right.

### S-Band antenna costing
**+0.015 kg**, ESTIMATE (flagged, not silently zero, not silently
upgraded to "sourced"). Real reference product is bus-scale (139g);
scaled to this platform's actual 30×30mm patch footprint.

## 5. Anything that didn't go as planned

- **`battery_visuals()` turned out to be dead code, not a live rendering
  bug.** Discovered only by grepping for call sites after fixing its
  content — the diff after regenerating `model.sdf` showed zero battery-
  related lines changed, which was the tell. Re-framed the finding
  accordingly rather than reporting a visual fix that never actually
  takes visual effect. Same category of finding as Phase 1's
  `GENTLE_RIGHTING_SPEED` discovery (assumed-live, turned out dead) —
  worth noting this is the second time in this project a flagged
  "needs fixing" constant/function turned out to be inert.
- **The S-Band antenna mass is still only weakly bounded**, same
  limitation Phase 1 already flagged for the UHF whip — the only real
  reference product found is bus-scale (139g), scaled down by area to a
  tiny 30×30mm patch. 15g is a defensible estimate, not a sourced figure.
  Flagged explicitly in `AUDIT_TABLE.md` row 10b, not silently upgraded.
- **Battery chemistry determination rests on engineering judgment, not
  a document that explicitly states "this is the final decision."**
  Git chronology was used as supporting evidence (Ni-MH code predates the
  paper's Li-ion claim being visible in this repo) but isn't proof of
  intent by itself, since the paper's authoring may have happened outside
  this repo before its "sync" commit. The stronger argument is the
  specific-real-part-vs-generic-label asymmetry and the realism argument
  (§4) — flagged here so the reasoning, not just the conclusion, is on
  record for review.
